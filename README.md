# SpaceDot

Двойной пробел → точка (Windows).

Простая утилита, которая превращает **два быстрых нажатия пробела** в **точку + пробел** — точно так же, как это работает на macOS и iOS при наборе текста.

## Что делает программа

- Отслеживает нажатия пробела глобально (во всех приложениях).
- Если два пробела нажаты подряд с интервалом менее 500 мс → удаляет эти два пробела и вставляет `. `.
- Опционально: тройной пробел → свой текст (по умолчанию `! `).

## Настройки

Левый клик по иконке в трее (или правый клик → «Настройки») открывает окно настроек. Там можно:

- назначить несколько клавиш («Добавить клавишу» → нажать нужную, Esc — отмена), по умолчанию — пробел;
- для каждой клавиши задать текст для двойного и тройного нажатия;
- задать общий интервал между нажатиями;
- включить автозапуск вместе с Windows (запись в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).

 Настройки сохраняются в `%APPDATA%\SpaceDot\config.json`.

## Требования

- Windows (протестировано на Windows 10/11)
- Go 1.21+ (рекомендуется 1.22)
- MinGW-w64 / gcc (для cgo в robotgo и gohook)

## Установка зависимостей

```bash
go mod init double-space-to-dot
go get github.com/robotn/gohook
go get github.com/go-vgo/robotgo
go get fyne.io/fyne/v2
go mod tidy
```

## Сборка проекта

Программа работает в фоне с иконкой в системном трее (выход — правый клик по иконке → «Выход»).
Чтобы при запуске не открывалось консольное окно, собирайте с флагом `-H windowsgui`:

```bash
go mod tidy
go build -ldflags "-H windowsgui -s -w" -o SpaceDot.exe
```

## Обновления

В настройках есть галочка «Обновлять автоматически» и кнопка «Проверить обновления».
Программа берёт новые версии из [GitHub Releases](https://github.com/Sereja-Lebeda/SpaceDot/releases):
скачивает `SpaceDot.exe` из последнего релиза, подменяет себя и перезапускается.
После обновления показывается окно «Что нового» с описанием релиза.

Как выпустить новую версию:

1. Поднять `version` в `updater.go` (например, `1.0.0` → `1.1.0`) и собрать exe.
2. Закоммитить и запушить.
3. На GitHub → Releases → «Draft a new release»: тег `v1.1.0`, в описание — список изменений
   (Markdown, он и будет в окне «Что нового»), прикрепить файл `SpaceDot.exe`.
