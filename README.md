# SpaceDot

Текстовые замены по двойному и тройному нажатию для Windows. Например:

- **Пробел ×2 → `. `**
- **Shift + . ×2 → `,`**
- **Пробел ×3 → `! `** (включается отдельно)

Программа работает в фоне с иконкой в системном трее. Левый клик открывает настройки, правый — меню с паузой и выходом.

## Правила

1. На вкладке «Правила» нажмите «Добавить сочетание».
2. Нажмите печатную клавишу или удерживайте Shift и нажмите клавишу. Esc отменяет запись.
3. Укажите текст для двойного и, при необходимости, тройного нажатия.
4. Выберите раскладку: любую или конкретный установленный язык.
5. Нажмите «Сохранить». Рядом появится подтверждение применения.
6. Откройте вкладку «Проверка» и попробуйте сочетание в тестовом поле.

Для запятой запишите **Shift + физическая клавиша точки**, введите `,` в поле двойного нажатия и сохраните. Затем удерживайте Shift и дважды нажмите эту клавишу. Shift также можно отпускать между нажатиями; левый и правый Shift равнозначны.

Обычная клавиша и сочетание с Shift имеют независимые правила. Правило для конкретного языка раскладки имеет приоритет над правилом «Любая раскладка». Раскладки с одинаковым Windows LANGID используют одно правило.

Каждое правило можно выключить, сохранив его настройки. Пустой результат оставляет обычный ввод. Первое нажатие печатается сразу; при втором символы заменяются результатом. Если включено тройное нажатие, третье заменяет результат двойного на результат тройного.

Поддерживаются буквы, цифры, знаки и пробел. Назначение сохраняет Windows virtual-key код клавиши; текст результата вставляется через Unicode независимо от раскладки. Tab, Enter, Backspace и навигационные клавиши не назначаются. Ctrl, Alt и Win не поддерживаются: их сочетания выполняют команды приложений, а не обычный ввод текста.

Удержание клавиши не считается серией отдельных нажатий. Щелчки мыши, навигация, другие клавиши, смена окна или языка раскладки сбрасывают серию. Собственные события вставки помечены и исключены из обработки.

## Настройки и пауза

- Общий интервал между нажатиями — от 100 до 2000 мс, по умолчанию 500 мс.
- Исключения приложений задаются именами exe через запятую, например `game.exe, WindowsTerminal.exe`. Регистр не учитывается.
- Пауза включается в окне или из трея и действует до продолжения или перезапуска приложения.
- Автозапуск использует `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
- Конфиг сохраняется в `%APPDATA%\SpaceDot\config.json`. Поддерживается старый формат конфигурации. Старые правила без Shift теперь работают только без модификаторов.
- «По умолчанию» восстанавливает стандартные правила в форме; для применения нужно сохранить.

Тестовое поле использует сохранённые правила, паузу, исключения и текущую раскладку так же, как обычные приложения. Чтобы добавить проверяемое правило, сначала сохраните его.

## Запуск

Скачайте `SpaceDot.exe` из [последнего релиза](https://github.com/Sereja-Lebeda/SpaceDot/releases/latest) и запустите. При обновлении вручную сначала завершите старую копию через трей.

Дополнительные параметры:

```powershell
.\SpaceDot.exe --settings
.\SpaceDot.exe --config C:\path\config.json --settings
```

`--settings` открывает окно при запуске; `--config` позволяет использовать отдельный конфиг. Не запускайте несколько копий с глобальной обработкой ввода одновременно.

## Сборка и проверка

Нужны Windows 10/11, Go 1.24+ и MinGW-w64 / gcc для графической части Fyne. Перехват и вставка клавиш используют Windows API; robotgo и gohook больше не нужны.

```powershell
go mod download
go test ./...
go vet ./...
go build -ldflags "-H windowsgui -s -w" -o SpaceDot.exe .
```

Для проверки гонок: `go test -race ./...` (нужен gcc с поддержкой race-сборки).

## Обновления

На вкладке «Настройки» доступны автоматическое обновление и ручная проверка. Программа скачивает `SpaceDot.exe` из [GitHub Releases](https://github.com/Sereja-Lebeda/SpaceDot/releases), заменяет себя и перезапускается. После обновления показывает описание релиза.

Для выпуска поднимите `version` в `updater.go`, выполните проверки, соберите exe, отправьте коммит и создайте релиз с тегом `v` + версия и файлом `SpaceDot.exe`.
