# SpaceDot 1.1.0

## Новое

- Двойные и тройные нажатия сочетаний Shift + клавиша. Например: Shift + . ×2 → запятая.
- Независимые правила для обычной клавиши и той же клавиши с Shift.
- Пауза и продолжение в окне настроек и системном трее.
- Выключатель каждого правила без удаления его настроек.
- Отдельные правила для языков раскладки; конкретный язык имеет приоритет над общим правилом.
- Исключения приложений по именам exe.
- Вкладки «Правила», «Проверка», «Настройки», карточки с кратким описанием замены и подтверждение сохранения.
- Тестовое поле для проверки сохранённых правил.
- Параметры --settings и --config для запуска с открытыми настройками и отдельным конфигом.

## Надёжность

- Перехват и Unicode-вставка переведены на Windows API; удалены зависимости robotgo и gohook.
- Собственный ввод определяется меткой события, а не временной задержкой.
- Удержание клавиши не запускает замену; быстрые отдельные нажатия учитываются.
- Серия сбрасывается при клике мышью, навигации, другой клавише, смене окна или языка раскладки.
- Tab, Enter, Backspace и клавиши навигации исключены из записи текстовых сочетаний.
- Настройки записываются через временный файл с последующей заменой.
- Добавлены тесты серий нажатий, конвейера событий, раскладок, исключений, интерфейса и сохранения настроек.

## Совместимость

Старые конфиги загружаются автоматически. Старые правила без Shift срабатывают только без модификаторов. Ctrl, Alt и Win не поддерживаются. При обновлении вручную завершите предыдущую копию через трей и запустите новый SpaceDot.exe.
