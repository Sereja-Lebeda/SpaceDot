# SpaceDot 1.1.1

- Увеличено окно «Что нового»: описание обновления удобнее читать.
- Поля настроек больше не растягиваются на всю ширину большого окна.
- Выключенные правила сворачиваются до заголовка; при включении все значения сохраняются.
- Автообновление показывает ошибки и повторяет неудачные попытки через 1–15 минут.
- После сохранения включённого автообновления проверка запускается сразу.
- Ручная и фоновая установка больше не запускаются одновременно.
